# Freakland Create — запуск

## 1. Firebase уже подключён
В `app.js` прописан конфиг проекта `reviewconstructor`. Ничего добавлять не нужно,
если это твой проект — просто выложи файлы на хостинг (см. пункт 3).

Если это не твой Firebase-проект, замени объект `firebaseConfig` в начале `app.js`
на конфиг своего проекта (Firebase Console → Project settings → General → Your apps).

В консоли Firebase включи:
- **Authentication → Sign-in method → Email/Password**
- **Firestore Database** (создать базу, режим не важен — правила ниже перекроют доступ)

## 2. Загрузи правила безопасности
Файл `firestore.rules` нужно применить в Firebase Console:
**Firestore Database → Rules** → вставить содержимое файла → **Publish**.

Без этого либо база будет полностью открыта (если оставить тестовый режим),
либо запись вообще не будет проходить.

## 3. Первый запуск — регистрация главного админа
1. Открой сайт, нажми **Войти → Зарегистрироваться**.
2. Зарегистрируйся с ником **freakland** (это задано в `app.js` в константе
   `MAIN_ADMIN_NICKNAME` — можно поменять на любой другой ник ДО первой регистрации).
3. Этот аккаунт автоматически станет главным админом — сможет добавлять игроков,
   назначать других админов (кнопка «Админы» рядом с профилем) и смотреть лог
   действий (кнопка со списком).
4. Все остальные регистрируются как обычные игроки без прав на редактирование.

## 4. Хостинг
Проект — набор статичных файлов (`index.html`, `app.js`, `styles.css`, `assets/`).
Подойдёт:
- **Firebase Hosting** (`firebase init hosting`, `firebase deploy`) — раз уж база тоже в Firebase;
- либо любой другой статик-хостинг (Netlify, Vercel, GitHub Pages и т.п.).

Важно: домен, с которого открывается сайт, должен быть добавлен в
**Authentication → Settings → Authorized domains**, иначе вход/регистрация не сработают.

## Структура данных Firestore
- `catalog/players` — один документ со списком всех игроков (публичное чтение).
- `users/{uid}` — профиль: `nickname`, `nicknameLower`, `isAdmin`, `isMain`, `createdAt`.
- `tierlists/{uid}` — личные тирлисты каждого пользователя.
- `logs/{autoId}` — лог действий админов, виден только главному админу.
